# 운동기록 (workout-logger)

헬스장용 개인 운동기록 PWA. 루틴 짜기, 세트별 무게·반복 기록, 휴식 타이머, 유산소 스톱워치·카운트다운, 달력과 지난 기록을 지원한다.

## 실행

```
node dev-server.cjs   # http://localhost:8732
```

아이폰: Safari로 접속 → 공유 → "홈 화면에 추가" → 전체화면 앱처럼 사용(오프라인 동작).

## 운동 중 사용

- 진행 중인 근력 운동은 탭을 옮기거나 새로고침해도 이어서 기록한다. 아직 추가하지 않은 무게·횟수 입력도 기기에 보관한다.
- 기록한 세트는 운동 화면에서 수정하거나 삭제할 수 있다. 휴식 시간은 조절하거나 건너뛴다.
- 유산소는 스톱워치 또는 카운트다운으로 측정하고 일시정지·재개한다. 카운트다운이 끝나면 설정한 시간을 기록한다.
- 루틴의 이름·운동 목록·순서를 수정할 수 있다. 진행 중인 루틴의 수정·삭제는 운동 종료 후 가능하다.

## 백그라운드와 복원

타이머는 화면 갱신 횟수 대신 시작 시각과 실제 경과 시간을 계산한다. 다른 앱으로 이동하거나 화면을 잠근 동안도 시간이 포함되며, 돌아오면 즉시 표시를 맞춘다. 휴식은 종료 시각을 저장하고, 유산소는 누적 밀리초와 실행·정지 상태를 저장하므로 새로고침 후에도 복원된다. 일시정지한 동안은 운동 시간에 포함하지 않는다.

iOS 등에서 브라우저가 백그라운드 실행을 중단하면 그 순간의 소리·진동은 보장할 수 없다. 이 경우 앱에 돌아온 시점에 완료를 처리한다. 홈 화면에 설치해도 앱이 계속 코드를 실행하도록 강제할 수는 없다. [WebKit의 백그라운드 동작 설명](https://webkit.org/blog/8970/how-web-content-can-affect-power-usage/).

## 백업

루틴 화면에서 JSON 백업을 내보내거나 불러온다. 불러오기 전에 파일의 내용을 검사하고 기록 개수를 표시한다. 기본 선택인 **기존 기록에 합치기**는 현재 데이터를 유지하고 새 기록을 추가한다. 같은 ID의 기록은 현재 기기의 내용이 우선이다.

**전체 교체**는 현재 데이터를 백업 내용으로 바꾸므로 먼저 복구용 백업을 다운로드한다. 진행 중인 운동을 종료한 뒤 사용할 수 있다. 백업 JSON은 운동·루틴·기록·달력·메모를 담고, 실행 중인 타이머와 입력 초안은 해당 브라우저에 별도로 저장된다. 다른 기기로 진행 상태까지 옮기지는 않는다.

## 테스트

```
node --test
node --test tests/timer.test.js  # 타이머만 검증
```

브라우저 통합 검증은 별도 터미널에서 위 개발 서버를 실행한 다음 진행한다.

```
npm ci
npx playwright install chromium
npm run test:browser
```

320px 모바일 입력·수정·초안 복원, 타이머 중단·재개·새로고침, Chromium 실행 정지 후 경과 시간, 백업 취소·합치기·오류 처리를 검증한다. 테스트는 가상 기록만 사용하며 화면 캡처는 Git에서 제외된 `99_작업자료/browser-check/`에 저장한다.

타이머 테스트는 갱신이 없는 장시간 경과, 소수 초가 포함된 일시정지·재개, 실행·정지 상태의 복원, 휴식 시간 조절과 완료를 검증한다. 실제 휴대폰의 잠금 화면 소리·진동 동작은 별도 기기 확인이 필요하다.

## 구조

- `src/storage.js` localStorage 래퍼(주입 가능)
- `src/store.js` 운동/루틴/세션 CRUD + 영속화
- `src/history.js` 저번 무게·총 볼륨 조회(순수)
- `src/timer.js` 시각 기반 경과·휴식 타이머와 저장 가능한 상태(순수)
- `src/ui.js` 렌더 전용(계산 금지)
- `src/main.js` 스토어·UI·타이머 배선
- `manifest.webmanifest` / `sw.js` PWA(오프라인 셸 캐시 + 홈화면 추가)
